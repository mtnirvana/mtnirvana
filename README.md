Framework completo de automação de testes para o site [Automation Exercise](https://www.automationexercise.com), combinando **testes E2E Web (Cypress)**, **testes de API (Cypress)**, **testes de Performance (k6 + Core Web Vitals)** e **CI/CD automatizado (GitHub Actions)**, tudo orquestrado por inteligência artificial com governança rígida e consumo otimizado de tokens.

✔ 61 casos de teste: 26 E2E · 14 API · 21 Performance<br>

✔ CI/CD automatizado via GitHub Actions — 4 jobs orquestrados com Allure Report publicado no GitHub Pages<br>

✔ Otimização de ~70% no consumo de tokens de IA — utilizando leitura seletiva + Playwright CLI (~76% mais econômico que MCPs por não precisar carregar todas as tools no contexto)<br>

✔ Page Object Model com 9 Page Objects e dados centralizados<br>

✔ Self-healing de seletores em 5 níveis (Playwright CLI, Chrome DevTools MCP, Playwright MCP, Selenium MCP)<br>

✔ Documentação completa: documentos executivos, técnicos, BDD/Gherkin e relatórios de performance<br>

✔ Screenshots, GIFs e vídeos gerados automaticamente<br>

✔ Relatório unificado Allure com histórico entre execuções
